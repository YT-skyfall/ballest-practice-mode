# Practice Mode Roadmap

## v1.1.0 — Planned / In Progress

### UI
- Dedicated **Mods** submenu from the Ballest main menu.
- Dedicated **Practice Mode** submenu so practice controls do not clutter Ballest's normal pause/results menus.
- Configurable Practice HUD modes: **Compact**, **Full**, and **Off**.
- Continue polishing the native Ballest-style layout, labels, spacing, and menu presentation.

### Practice points
- Multiple practice-point / save-loc slots.
- Configurable save/load keybinds.
- Save and restore the ball's movement state with a practice point:
  - position
  - rotation
  - linear velocity
  - angular velocity
- **Restore Momentum** option so a saved point can resume at the speed/direction of a real run instead of always restarting stationary.

### Practice tools
- Section timing / practice splits.
- Practice-session stats.
- Better in-game feedback/notifications when points are saved, loaded, or changed.

> v1.1.0 is still in development. Items listed here are planned or in progress and may change before release.
