GitHub Pages setup

Recommended repository layout:
- Keep this `site` folder as the website source.
- In GitHub Settings -> Pages, choose GitHub Actions or publish this folder
  through a Pages workflow.

The website automatically builds its GitHub Release download URLs when it is
running on <owner>.github.io/<repo>/.
